GRAVEYARD ORBIT TWEAKS (0.1.1)
=============================

WHAT THIS IS
  A standalone BepInEx plugin with balance changes for Graveyard Orbit:
  cheaper drones, cheaper repairs, and an upgrade path for the Igniter.
  It does not require the co-op mod; both can be installed together.

REQUIREMENTS
  - Windows 10/11, or Linux / Steam Deck (Proton)
  - Graveyard Orbit installed through Steam (AppID 4654120)

INSTALL (SAME ON WINDOWS AND LINUX)
  1. Close Graveyard Orbit.
  2. In Steam, right-click Graveyard Orbit > Manage > Browse local files.
     That opens the game folder (the one containing GraveyardOrbit.exe).
  3. Download the release zip:
       https://github.com/Grokent/graveyard_orbit_tweaks/releases/latest/download/GraveyardOrbit-Tweaks-0.1.1.zip
  4. Extract EVERYTHING from the zip into the game folder that opened in step 2.
     It only adds files; nothing in the original game is replaced:
       winhttp.dll
       doorstop_config.ini
       .doorstop_version
       changelog.txt
       BepInEx/...
  5. Linux / Steam Deck (Proton) ONLY: add this launch option once
     (game > Properties > Launch Options):
       WINEDLLOVERRIDES="winhttp=n,b" %command%
     Windows needs no launch options.
  6. Launch the game through Steam normally.

CHANGES
  Drone prices and repairs
    - Miner buy:    $800   -> $400
    - Hauler buy:   $1,200 -> $600
    - Seeker buy:   $1,500 -> $750
    - Upgrade steps: $200 / $350 / $550 / $850 / $1,300
                     -> $100 / $175 / $275 / $425 / $650
    - Repair:       $300   -> $100
    Level prices are halved after the per-contract progression multiplier, so
    later contracts scale from the reduced base too.

    Reasoning: the buy, upgrade and repair prices were too high for the utility
    drones actually provide. Losing one Miner cost a four-figure sum to replace
    and a $300 repair felt worse than losing the drone. Drones are fragile and
    their output is incremental, so these costs turned the drone bay into a
    money sink instead of a progression choice.

  Igniter upgrades
    - Level 1: 3 rocks/s (vanilla)
    - Level 2: 4.5 rocks/s for $200
    - Level 3: 6 rocks/s for $350
    Uses the same LEVEL UP card, hold-to-upgrade, tooltip and pad navigation as
    the laser and press; the card maxes at level 3. The upgraded rate applies to
    the live belt simulation, and the machine card shows the current rate.

    Reasoning: the press already upgrades at $180 and $300, while the igniter
    stopped at level 1. $200 / $350 keeps the igniter in line with the press
    curve and gives it a real progression path.

  Future tweaks
    - Add an upgrade path for the Kickback (internally MachineKind.Rebate), the
      only refinery machine with no upgrades today.
    - Further cost tweaks as the economy is played through.

LOGS
  BepInEx/LogOutput.log
  Look for: [Graveyard Orbit Tweaks] Tweaks loaded

UNINSTALL
  Delete BepInEx/plugins/GraveyardOrbit.Tweaks/
  Remove winhttp.dll, doorstop_config.ini, .doorstop_version, changelog.txt and
  BepInEx/ only if you do not use any other BepInEx mod.

NOTE
  BepInEx injects through winhttp.dll. Some antivirus tools may flag it as a
  false positive; that file is part of the standard BepInEx mod loader.
